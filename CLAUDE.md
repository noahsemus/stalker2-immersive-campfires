Purpose: mod for **S.T.A.L.K.E.R. 2 (UE5.5)** that lets Skif eat, drink, open the PDA and inspect artifacts while seated at a campfire (stretch: sleep / rest at a campfire). Renamed from "Campfire Actions" on 2026-09-27 (GitHub repo `noahsemus/stalker2-immersive-campfires`; the old URL redirects).

## Carried over from ImmersiveDialogue (verified there, 2026-09-13 → 09-27)
- **Blueprint host that overrides nothing:** a `ModWorldSubsystem` Blueprint (NewContent, `OnTick`) can spawn an actor that calls `EnableInput` and binds EnhancedInputAction events (Immersive HUD does exactly this with `IA_QuickSlot1-4` / `IA_Inventory`). The subsystem only runs if the editor's **Package Mod** button generated `Autogenerated_<n>_WorldSubsystemData` into the mod's Content (headless cook won't generate it, but cooks it once it exists); that asset goes in `OverridePackages.txt`.
- **Cook rules:** a NewContent Blueprint keeps references to other NewContent assets; an *override* Blueprint's reference to a mod-only asset is silently nulled; a package in both classifier lists is cooked into neither; the cook takes everything in the mod's `Content` folder regardless of the lists.
- **Overridden assets exist twice at runtime** (`/Game/...` and `/<Mod>/...`). The editor redirects `/Game` picks of an overridden asset to the mod path, and only the game-path object gets the player's rebinds, so load it by path string when that matters.
- **Rebinds:** mapping rows need `SettingBehavior = OverrideSettings` + a `PlayerMappableKeySettings` with the game's mappable name, or the player's Options > Controls rebinds (`%LOCALAPPDATA%\Stalker2\Saved\CustomizeControls.cfg`) never reach them. `make_imc_override.py` moves the exploration rows' real settings objects over.
- **Mount order:** priority = 3 + 100 × (N+1) for a `_N_P` suffix. Release override pak `zzz_ImmersiveCampfires_20_P.*`; dev test paks install as `_30_P` (beat a Vortex-installed release copy); NewContent keeps the kit's file name.
- `Print String` is stripped in Shipping; trace Blueprints with visible side effects or a dev-box UE4SS probe. Delete any `Autogenerated_*_ActorReplacementData.uasset` the editor drops in Content unless an actor override needs it.
- Editor traps: save before Compile on big edits; wait ~10 s after a save before cooking; Property Access nodes only in AnimGraphs; after any asset rename, Compile (bytecode is stale) and re-check pins. Editor remote Python execution is on (Project Settings → Plugins → Python); `zonekit/tools/ue_exec.py` runs scripts in the open editor in seconds, but `duplicate_asset` returns None there for /Game sources (use the headless commandlet).
- Engine source 5.5 is readable with `gh api repos/EpicGames/UnrealEngine/contents/...?ref=5.5`.

## Rules
- **ZoneKit first.** Grep the dumps and cfgs, and ask Noah to open assets in the Mod Editor, before any blind build/test cycle. Most `/Script/Stalker2` classes are native with no graph; look for assets that USE them.
- **Assets this mod may override:** `IMC_PlayerCA`, the sit-actor Blueprint (fallback host only), `BP_Stalker2Bonfire` (sleep stretch only). **Never** `BP_Stalker2Character`, `AnimBP_Player`, `AnimBP_player_bh`, `IMC_Exploration`, or any `.cfg`: ImmersiveDialogue overrides the pawn, other popular mods (ZST, Immersive HUD) override `AnimBP_Player` / `IMC_Exploration`, and per asset the last-mounted pak wins outright.
- **Canary.** Every test build keeps an extra key on `IA_PlayerCAExit` so "override not loaded" and "action vetoed" are distinguishable in game. Remove it for release.
- **Change discipline.** One change per cook (5-6 min), tested by Noah before the next. Checkpoint working states as tagged commits with the cooked paks in `zonekit/builds/`. Roll back to the last checkpoint at the first regression.
- **No versions, commits of candidates, tags or releases unless Noah says so.** Harness/doc commits are fine; test builds stay uncommitted until he confirms.
- **UE4SS is dev-only.** A read-only probe (ImmersiveDialogue's `ImmDlgProbeCpp` / Lua shape, listed before `UObjectCacheMod` in `mods.txt`) may run on the dev box. Prove it captures before asking Noah for a run. Nothing UE4SS ships.

## Pipeline (details in BUILD.md)
- Plugin lives at `<kit>\Stalker2\Mods\ImmersiveCampfires\` (the editor's source of truth); mirror changed `.uasset`s back into `zonekit/ImmersiveCampfires/` after every save. Classifier lists live in `zonekit/tools/classifier/ImmersiveCampfires/` and are copied to `<kit>\Stalker2\SavedMods\PackageClassifier\ImmersiveCampfires\`.
- Cook + install: `powershell -File zonekit\tools\cook_and_install.ps1` (RunUAT `GSCCookMod` with `-UnrealExe=<kit>\Stalker2\Binaries\Win64\Stalker2ModEditor-Win64-Shipping-Cmd.exe`; install waits for `Stalker2-Win64-Shipping.exe` to exit). The editor may stay open. `revert_paktest.ps1` removes the dev copy.
- Headless editor scripts: `Stalker2ModEditor-Win64-Shipping-Cmd.exe "<kit>\Stalker2\Stalker2.uproject" -run=pythonscript -script=<file> -unattended -nosplash -stdout -NoShaderCompile` (~4.5 min; editor must be closed for asset-moving scripts).
